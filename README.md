# Commute.ly

Kerangka monorepo untuk WebGIS Commute.ly. Tahap ini hanya menyiapkan struktur kerja; belum ada implementasi API, basis data, AI, routing, maupun antarmuka fitur.

## Direktori utama

```text
frontend/  # aplikasi Next.js + TypeScript + Tailwind CSS + MapLibre GL
backend/   # layanan FastAPI dan batas domain spasial
data/      # data mentah, hasil olahan, dan keluaran spasial
docs/      # keputusan produk, arsitektur, data, dan API
scripts/   # utilitas operasional/ETL yang akan dibuat kemudian
```

Lihat README di tiap direktori untuk batas tanggung jawabnya.
